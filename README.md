*CONVERSOR ASCII*

ASCII

Conversos ASCII desktop para Windows desenvolvida em C# com Windows Forms (.NET 10).

Sobre o projeto

O projeto contém um conversor ASCII, implementado na classe CodigoASCII e utilizado pela interface gráfica principal (Form1). A aplicação possui também uma segunda janela (Form2) contendo uma tabela com códigos ascii.

Converte código ASCII em texto.

Tecnologias
C#
Windows Forms
.NET 10.0 (net10.0-windows)


Estrutura do projeto
Arquivo	Descrição
Program.cs	Ponto de entrada da aplicação
Form1.cs / Form1.Designer.cs 	Interface Inicial
Form2.cs / Form2.Designer.cs	Tabela com os Codigos ASCII
CodigoASCII.cs	classe (Molde para criação do objeto)


Pré-requisitos
Windows 10 ou superior


Como usar

Com o arquivo "Gerador Ascii Trabalho ADS.xlsx" Escreva o texto que deseja obter o código ASCII, copie o valor da célula que apresenta os códigos ASCII e cole na ferramenta. clique em converter para Texto.
